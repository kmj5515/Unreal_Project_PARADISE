## 1) 로비/매치 진입 루프 (가장 먼저 완성)
목표: 포트폴리오 데모 시작 30초 안에 "로비 -> 시작 -> 맵 진입"이 보이게.

- [ ] 로비 상태 구조 확정 (`혼자 시작` / `방장 시작` / `대기 인원 표시`)
- [ ] 방장 전용 시작 버튼 권한 처리 (클라 UI + 서버 검증)
- [ ] 시작 버튼 클릭 시 "UI 맵(브리핑/진입 UI)" 표시
- [ ] UI 맵에서 "진입 버튼" 누르면 게임 맵으로 서버 이동 (`ServerTravel`)
- [ ] 맵 이동 후 플레이어 스폰/초기화/입력 정상 동작 확인

---

## 2) 게임맵 코어 플레이 (파쿠르 + 전투)
목표: 게임 맵에 들어가면 "이동/파쿠르/공격"이 즉시 동작.

- [ ] 파쿠르 몽타주 3종(Low/Window/High) 최종 세팅 및 튜닝
- [ ] 파쿠르 실패/불가 피드백(UI 또는 디버그 텍스트) 추가
- [ ] 근접 공격 히트 판정 및 데미지 연동 최종 검증
- [ ] 원거리 공격 히트 판정 및 데미지 연동 최종 검증
- [ ] HUD 최소 버전 (체력 + 상호작용 프롬프트)

---

## 3) 좀비 AI (소리 반응 + 추격/공격)
목표: 총/문/차 소리에 좀비가 반응하는 PvE 체감 확보.

- **초기 범위:** 평지 + NavMesh 기준 추격만 우선 (파쿠르/비정형 지형 추격은 제외)
- [ ] 좀비 AIController + Behavior Tree 기본 루프 (대기 -> 탐지 -> 추격 -> 공격)
- [ ] Perception(특히 청각) 기반 소리 탐지 설정
- [ ] 플레이어 소음 이벤트 규격화 (무기, 문, 차량 공통)
- [ ] 좀비 공격/피격/사망 기본 처리
- [ ] 멀티 환경에서 좀비 타겟 변경/추격/공격 동기화 검증

---

## 4) 월드 인터랙션 목표 기능
목표: 맵 오브젝트가 게임플레이를 만든다는 인상을 주기.

- [ ] 자동차 공격 시 사이렌 ON (소리 발생 + 좀비 어그로 유도)
- [ ] 문 타격 시 소리 이벤트 발생 (좀비 청각 반응)
- [x] 무기 히트 수신 공통 인터페이스 (`IParadiseWeaponHitReactable` — 맵 액터에서 `ReactToWeaponHit` 구현)

---

## 5) 탈출/복귀/보상 루프
목표: 한 판의 시작-진행-종료를 포트폴리오에서 보여주기.

- [ ] 게임맵 탈출 트리거(하수구 터치) 구현
- [ ] 탈출 시 로비로 복귀 처리 (서버 기준 상태 전환)
- [ ] 결과/보상 UI 기본 틀 (획득 자원/성공 여부)
- [ ] 보상 데이터 저장 구조(임시라도) 연결

---

## 6) 데모 우선순위 (빠른 제작용)
아래 순서대로 구현하면 포트폴리오 시연본이 가장 빨리 나옴.

1. 로비에서 시작 버튼으로 게임맵 진입 (1단계 완료)
2. 게임맵에서 파쿠르 + 공격 동작 (2단계 핵심 완료)
3. 좀비가 소리 듣고 추격/공격 (3단계 핵심 완료)
4. 차 사이렌/문 소리 등 맵 오브젝트 반응 (4단계 핵심 완료)
5. 하수구 탈출 -> 로비 복귀 -> 보상 UI (5단계 완료)

---

## 7) 최종 폴리싱/문서화
- [ ] 네트워크 최적화 (RPC/복제 빈도, relevancy, dormancy)
- [ ] 디버그 명령/치트 (좀비 스폰, 즉시 시작, 보상 지급 등)
- [ ] 포트폴리오 시나리오 녹화 (로비 -> 진입 -> 전투/파쿠르 -> 탈출 -> 보상)
- [ ] README/기술 문서/실행 가이드 최종 정리
